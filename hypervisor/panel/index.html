Before creating your first guest

Use your installer-created administrator account and enable administrative access in Cockpit when requested. Supply guest installation media, choose a storage pool, then select the default NAT network.

For a host installed inside vSphere, the outer VM must expose hardware-assisted virtualization. A detected KVM device does not replace a guest boot test.

This release manages a single host. AlphaFS, shared-storage clustering, Ceph, Kubernetes, and KubeVirt are not implemented in this candidate.

Powered by Rocky Linux, Cockpit Machines, QEMU/KVM, and libvirt. Candidate build: installation and VM lifecycle validation pending.
